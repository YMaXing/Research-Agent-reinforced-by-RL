<s slug="ai-agent-planning-ibm" type="golden_web">AI agent planning is the core process by which AI agents generate sequences of actions to reach defined goals. The IBM source explains that planning sits alongside perception, reasoning, memory, tool use, and learning modules in agent architectures, distinguishing planning agents from simple reactive agents by their ability to anticipate future states and produce structured plans before execution. Key concepts covered include goal definition, state representation, action sequencing, optimization, and collaboration in multiagent systems. The source explicitly names the ReAct framework as a methodology for dynamic decision-making that interleaves reasoning and action generation. Concrete examples include a self-driving car, robotic vacuum, warehouse robot, and chatbot decomposing travel planning. Frameworks mentioned are LangChain, GPT-style LLMs, and agentic workflows. No quantitative benchmarks appear.</s>
<s slug="building-effective-agents-anthropic" type="golden_web">The source "Building effective agents" (Anthropic, Dec 19, 2024) details production patterns for LLM agentic systems. It distinguishes predefined workflows from agents. Core building block is the augmented LLM. Five workflow patterns are presented: prompt chaining, routing, parallelization, orchestrator-workers, and evaluator-optimizer. Autonomous agents extend these with open-ended tool-use loops. Concrete examples include a coding agent solving SWE-bench tasks. Agents trade latency and cost for performance and succeed in trusted environments with sandbox testing and guardrails.</s>
<s slug="react-agent-from-scratch-with-gemini-2-5-and-langgraph" type="golden_web">LangGraph is a framework for building stateful LLM applications and constructing ReAct agents. ReAct agents iteratively reason, invoke tools, and update behavior from observations. The guide models the agent as a graph with State, Nodes, and Edges. A concrete weather-forecast agent is built step by step using get_weather_forecast tool, ChatGoogleGenerativeAI, and conditional edges. Execution uses graph.stream with multi-turn continuation shown.</s>
<s slug="react-agent-ibm" type="golden_web">The IBM source details ReAct agents as LLM-driven AI agents that integrate chain-of-thought reasoning with external tool use. ReAct agents operate through iterative thought-action-observation loops. ReAct prompting instructs the model to interleave thoughts with actions and output a final answer. Benefits include versatility, adaptability, explainability, and improved accuracy. The source contrasts ReAct with function calling.</s>
<s slug="react-synergizing-reasoning-and-acting-in-language-models" type="golden_web">ReAct is a prompting paradigm that interleaves free-form reasoning traces with task-specific actions generated by frozen LLMs such as PaLM-540B and GPT-3. On HotpotQA and FEVER the action space uses a three-function Wikipedia API. ReAct prompting outperforms Act-only baselines. On ALFWorld one- to three-shot ReAct reaches 71% average success rate. On WebShop one-shot ReAct improves success rate by 10% absolute. Finetuning PaLM-8B/62B on 3 000 correct ReAct trajectories makes it the strongest method.</s>
<s slug="towardsai_course-ai-agents" type="golden_code">The notebook demonstrates a complete ReAct implementation with Google’s Gemini. Key components include a mock search function registered in TOOL_REGISTRY, build_tools_xml_description, generate_thought, and generate_action supporting both ToolCallRequest and FinalAnswer outputs. The central react_agent_loop orchestrates up to max_turns iterations. Concrete tests show the loop answering factual questions and adapting on unknown queries before forced termination.</s>
<s slug="ai-agent-orchestration-ibm" type="exploitation">AI agent orchestration coordinates multiple specialized AI agents within a unified system. The source defines AI agents as autonomous entities powered by LLMs using function calling. Four orchestration types are detailed: centralized, decentralized, hierarchical, and federated. Benefits include enhanced efficiency, agility, and scalability. Challenges cover multi-agent dependencies and coordination failures.</s>
<s slug="building-react-agents-from-scratch-using-gemini-medium" type="exploitation">ReAct agents integrate reasoning and action in an iterative LLM-driven loop. The source explains three core features. Concrete components include SERP API, Wikipedia API, Pydantic models, and the Agent class. Three execution traces are provided for multi-hop queries. ReAct requires no code changes to add tools and supports both zero- and few-shot prompting.</s>
<s slug="from-llm-reasoning-to-autonomous-ai-agents-arxiv" type="exploitation">The source is a 2025 arXiv survey that positions ReAct as the foundational technique for combining chain-of-thought reasoning with tool calls. Key concepts include ReAct-style loops, Agentic RAG, and multi-agent orchestration. Concrete frameworks named are LangChain, LlamaIndex, CrewAI, and OpenAI Agents SDK. Specific data points include GAIA, HLE, and SimpleQA benchmarks.</s>
<s slug="gemini-function-calling-documentation" type="exploitation">Gemini Function Calling enables ReAct-style agent loops by letting Gemini models reason over user prompts and emit structured function calls. The documentation details a four-step flow: declare functions, send declarations, execute returned calls, and return results. Concrete techniques include parallel function calling and compositional loops. Supported models include Gemini 2.5 and 3.x series.</s>
